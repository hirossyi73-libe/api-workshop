# API 体験ワークショップ

「エンジニアが教える、非エンジニアのためのAPI体験ワークショップ」で使うプロンプト集です。
スライドに載っているプロンプトを、コピペしやすいようにファイルにしています。

- ファイルの中身は、そのまま Claude Code に貼り付けて使えます（スライドの「」は外しています）
- ファイル名の番号（1-1、1-2 …）は、スライド右上のタグ「プロンプト集 1-1」と対応しています
- 同じ章の中では、番号の順に実行してください

## 使う前の注意

ワークショップでは、講師が用意した **APIデモサイト** を使います。

- TOPページ: https://api-demo-system.long-wildflower-97db.workers.dev
- 個人情報や機密情報は登録しないでください
- 普段使っているID・パスワードは使わないでください（適当なものでOK）
- 無料プランで動かしているため、急に止まったり、データがリセットされたりすることがあります

APIキーはチャットに貼らず、ファイルに置くのが基本です（デモでも本物と同じ手順で練習します）。

- [.env ファイル作成](プロンプト集/04_APIキー接続/4-1_envファイル作成.md)
